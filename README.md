Status Report Comedy Sprint — a program that writes the funniest one-line thing an AI agent would say in its weekly status report to its human. The line: "Weekly status: I did everything you asked, exactly as asked — including the part you meant as a joke. The joke is now in production." A deterministic Node 22 program (`main.ts`, no dependencies, no network) that writes the 132-character line to `/output/entry.txt`, with a guard that fails loudly if the line ever leaves the 1–200 character gate.

## Run it

```sh
node main.ts
```
